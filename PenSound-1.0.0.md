### UI/UX Improvements
- Redesigned onboarding flow with updated visuals matching the main interface
- Accessibility permission is now requested within the onboarding flow with context, rather than as an unexpected system prompt at launch
- Added an Accessibility permission banner in the menu bar panel when access has not been granted

- Increased crayon volume for a more present, physical feel
